## 1. GRAMMAR MASTER TABLE: ALL 12 TENSES

| Tense | Formula (Active Voice) | Signal Words / Usage | Example |
|---|---|---|---|
| **Simple Present** | V1 / V1+s/es | Always, usually, daily, habits, facts | He **writes** code every day. |
| **Present Continuous** | is/am/are + V-ing | Now, currently, at present | He **is writing** code right now. |
| **Present Perfect** | has/have + V3 | Just, recently, already, yet, so far | He **has written** the code. |
| **Present Perfect Cont.** | has/have been + V-ing | Since, for (action still continuing) | He **has been writing** code since 9 AM. |
| **Simple Past** | V2 | Yesterday, ago, last year, in 2010 | He **wrote** the code yesterday. |
| **Past Continuous** | was/were + V-ing | While, when (background action in past) | He **was writing** code when the power failed. |
| **Past Perfect** | had + V3 | Before, after, by the time (older of 2 past actions) | He **had written** the code before the boss arrived. |
| **Past Perfect Cont.** | had been + V-ing | For/since (continuing up to a point in past) | He **had been writing** code for 2 hours before the crash. |
| **Simple Future** | will/shall + V1 | Tomorrow, next week, soon | He **will write** the code tomorrow. |
| **Future Continuous** | will be + V-ing | At this time tomorrow | He **will be writing** code at 10 AM tomorrow. |
| **Future Perfect** | will have + V3 | By tomorrow, by next year (deadline) | He **will have written** the code by 5 PM. |
| **Future Perfect Cont.** | will have been + V-ing | By next year, for 5 years | By next year, he **will have been writing** code for a decade. |

## 2. ARTICLES QUICK REFERENCE DECISION TREE

**Step 1:** Is the noun countable?
- NO (e.g., water, information, furniture) -> Usually ZERO article, unless specific (The water in this glass).
- YES -> Go to Step 2.

**Step 2:** Is the noun singular or plural?
- PLURAL (e.g., cars, people) -> Usually ZERO article for general (Cars are fast), or THE for specific (The cars in my garage).
- SINGULAR -> Go to Step 3.

**Step 3:** Is the speaker referring to a specific, known, or previously mentioned item?
- YES -> Use **THE**. (e.g., Bring me the book I gave you).
- NO -> Use **A** or **AN**. Go to Step 4.

**Step 4:** Does the word start with a VOWEL SOUND (not just a vowel letter)?
- Vowel Sound (a, e, i, o, u sound) -> Use **AN**. (An apple, an hour, an honest man, an MP).
- Consonant Sound -> Use **A**. (A university, a one-eyed man, a European).

## 3. CONDITIONAL SENTENCES AT A GLANCE

| Type | Condition (If clause) | Result (Main clause) | Usage | Example |
|---|---|---|---|---|
| **Zero (0)** | Present Simple (If V1) | Present Simple (V1) | Universal truths, scientific facts | If you heat ice, it melts. |
| **First (1)** | Present Simple (If V1) | Future Simple (Will + V1) | Real/Possible future situations | If he studies, he will pass. |
| **Second (2)** | Past Simple (If V2) | Would + V1 | Unreal/Imaginary present/future | If I won the lottery, I would buy a car. |
| **Third (3)** | Past Perfect (If had V3) | Would have + V3 | Unreal past (Regrets) | If she had studied, she would have passed. |

> [!WARNING]
> NEVER use "will" or "would" inside the "if" clause itself. 
> Incorrect: If it *will* rain, I will stay home. 
> Correct: If it *rains*, I will stay home.

## 4. PREPOSITIONS CHEAT SHEET (Time & Place)

| Preposition | Usage for Time | Usage for Place |
|---|---|---|
| **AT** | Precise times (at 5 PM, at noon, at night) | Specific points (at the door, at the bus stop) |
| **ON** | Days and dates (on Monday, on 4th July) | Surfaces (on the table, on the floor, on the wall) |
| **IN** | Months, years, seasons, long periods (in 1999, in summer, in July) | Enclosed spaces, cities, countries (in the box, in London, in India) |
