## 1. Introduction: What is Voice?

Voice describes the relationship between the verb and the subject.
- **Active Voice:** The subject performs the action. (Subject = Doer)
  *Formula:* Subject + Action Verb + Object
  *Example:* The developer (S) wrote (V) the code (O).
- **Passive Voice:** The subject receives the action. (Subject = Receiver)
  *Formula:* Object + Auxiliary "Be" + V3 (Past Participle) + by + Subject
  *Example:* The code (O) was written (V3) by the developer (S).

> [!IMPORTANT]
> **Placement Relevance:** Active/Passive conversions are guaranteed 2-3 questions in **TCS NQT**, **Capgemini**, and **Cognizant**. They test your ability to maintain tense and handle special cases (two objects, modals, commands).

---

## 2. General Rules for Conversion

1. Identify the Subject (S), Verb (V), and Object (O).
2. Swap the S and O. The Object becomes the new Subject.
3. Change the verb to its Passive form: **Appropriate "Be" verb + V3 (Past Participle)**.
4. Add the preposition "by" before the original subject (the doer).
5. Ensure the tense remains exactly the same! (Do NOT change past to present).

---

## 3. Tense-by-Tense Conversion Table

*Note: The Perfect Continuous tenses (Present, Past, Future) and the Future Continuous tense are generally NOT passivized in modern English.*

| Tense | Active Voice Structure | Passive Voice Structure | Example (Active -> Passive) |
| :--- | :--- | :--- | :--- |
| **Simple Present** | V1 / V1+s/es | is/am/are + V3 | S: He writes code.<br>P: Code is written by him. |
| **Present Continuous**| is/am/are + V-ing | is/am/are + being + V3 | S: He is writing code.<br>P: Code is being written by him. |
| **Present Perfect** | has/have + V3 | has/have + been + V3 | S: He has written code.<br>P: Code has been written by him. |
| **Simple Past** | V2 | was/were + V3 | S: He wrote code.<br>P: Code was written by him. |
| **Past Continuous** | was/were + V-ing | was/were + being + V3 | S: He was writing code.<br>P: Code was being written by him. |
| **Past Perfect** | had + V3 | had + been + V3 | S: He had written code.<br>P: Code had been written by him. |
| **Simple Future** | will/shall + V1 | will/shall + be + V3 | S: He will write code.<br>P: Code will be written by him. |
| **Future Perfect** | will have + V3 | will have + been + V3 | S: He will have written code.<br>P: Code will have been written by him. |

> [!TIP]
> **Memory Trick:**
> - Continuous tense in Active ALWAYS requires "**being**" in Passive.
> - Perfect tense in Active ALWAYS requires "**been**" in Passive.
> - Simple tense uses the base "be" verb (is/are/was/were).

## 4. Special Cases in Passive Voice

### 4.1 Sentences with Two Objects (Direct & Indirect)
When a sentence has two objects, either can become the subject in passive voice.
*Active:* The manager gave **me** (IO) a **bonus** (DO).
*Passive 1 (IO as Subject):* **I** was given a bonus by the manager. (Preferred)
*Passive 2 (DO as Subject):* A **bonus** was given to me by the manager.

### 4.2 Sentences with Modals
**Rule:** Modal + be + V3.
*Active:* You must finish the project.
*Passive:* The project **must be finished** by you.
*Active:* He should have deployed the code. (Modal Perfect)
*Passive:* The code **should have been deployed** by him.

### 4.3 Interrogative Sentences (Questions)
Keep the sentence interrogative. Do not change it to a statement!
*Active:* Did the client approve the design? (Simple Past)
*Passive:* **Was** the design **approved** by the client?
*Active:* Who wrote this script?
*Passive:* **By whom** was this script written?

### 4.4 Imperative Sentences (Commands/Requests)
**Rule:** Let + Object + be + V3.
*Active:* Shut the server down.
*Passive:* **Let** the server **be shut** down.
*(Alternative for advice):* The server should be shut down.
*(Alternative for request):* You are requested to shut the server down.

### 4.5 Prepositions Fixed to Verbs
Do NOT drop the preposition attached to the verb in the active voice.
*Active:* They laughed at the new intern.
*Passive:* The new intern was **laughed at** by them. (Missing 'at' is a common exam trap).

### 4.6 Impersonal Passives
Used for reporting beliefs, rumors, or thoughts without specifying a subject.
*Active:* People say that he is a genius.
*Passive 1:* **It is said** that he is a genius.
*Passive 2:* He is **said to be** a genius. (Highly tested in Infosys).

### 4.7 Verbs that do NOT take 'by'
Some past participles take prepositions other than 'by'.
- Known **to** (NOT known by)
- Surprised **at**
- Filled **with**
- Interested **in**
- Satisfied **with**
*Active:* I know him.
*Passive:* He is known **to me**. (If you write 'by me', it's wrong!).

### 4.8 The 'Get' Passive and Causative Verbs
**Get Passive:** Used in informal English for accidental or negative events.
*Example:* The server **got hacked** yesterday. (Meaning: was hacked).

**Causative Have/Get:** Used when you cause someone else to do something.
*Active (Causative):* I had the developer rewrite the code.
*Passive (Causative):* I had the code **rewritten** by the developer.

### 4.9 Sentences that CANNOT be Passivized
Only **Transitive verbs** (verbs with direct objects) can be passivized. **Intransitive verbs** cannot.
*Active:* The system crashed. (No object. Cannot be passive).
*Active:* The team arrived at 9 AM. (No object. Cannot be passive).

## 5. Key Takeaways Table

| Active Voice Feature | Passive Voice Transformation | Exam Trap |
| :--- | :--- | :--- |
| **Continuous Tense** | Add **being** | Forgetting 'being' in options. |
| **Perfect Tense** | Add **been** | Changing 'has' to 'had' (Tense shift). |
| **Who** | **By whom** | Missing the 'by'. |
| **Command (Shut it)** | **Let** it **be shut** | Overcomplicating the structure. |
| **Know / Satisfy** | Known **to** / Satisfied **with**| Using 'by'. |

## 6. Practice Questions & Solutions

**Q1. Change to Passive: "The QA team is testing the new module."**
(A) The new module is tested by the QA team.
(B) The new module was being tested by the QA team.
(C) The new module is being tested by the QA team.
(D) The new module has been tested by the QA team.
**✅ Answer: (C)**
**📖 Explanation:** The active sentence is Present Continuous (is testing). The passive must maintain Present Continuous by using "is being + V3" (is being tested).
**❌ Why (A) is wrong:** Simple Present.
**❌ Why (B) is wrong:** Past Continuous.
**❌ Why (D) is wrong:** Present Perfect.
**📏 Rule:** is/am/are + V-ing -> is/am/are + being + V3.
**⚡ Shortcut:** "ing" in active = "being" in passive.
**📊 Difficulty:** Easy
**🏢 Company:** TCS

**Q2. Change to Passive: "Who broke the build?"**
(A) By whom the build was broke?
(B) By whom was the build broken?
(C) Whom was the build broken by?
(D) Both B and C
**✅ Answer: (D)**
**📖 Explanation:** "Who" changes to "By whom". In a question, the auxiliary verb (was) must come before the subject (the build). Both B and C are grammatically acceptable, though B is more formal.
**❌ Why (A) is wrong:** Incorrect word order (was must come before the build) and wrong V3 ('broke' instead of 'broken').
**📏 Rule:** Who + V2 + O -> By whom + was/were + O + V3.
**⚡ Shortcut:** Who -> By whom. Keep question format (Verb before subject).
**📊 Difficulty:** Medium
**🏢 Company:** Infosys

**Q3. Change to Passive: "They will have deployed the application by Friday."**
(A) The application will be deployed by Friday.
(B) The application will have been deployed by them by Friday.
(C) The application would have been deployed by Friday.
(D) The application will have deployed by them by Friday.
**✅ Answer: (B)**
**📖 Explanation:** Future Perfect (will have deployed) changes to "will have been deployed".
**❌ Why (A) is wrong:** Simple Future.
**❌ Why (C) is wrong:** Changes 'will' to 'would' (this is a Narration rule, not Voice!).
**❌ Why (D) is wrong:** Missing 'been'.
**📏 Rule:** will have + V3 -> will have been + V3.
**⚡ Shortcut:** Perfect tenses need "been". Don't change the modal.
**📊 Difficulty:** Medium
**🏢 Company:** Wipro

**Q4. Change to Active: "The problem must be resolved by the architect."**
(A) The architect resolves the problem.
(B) The architect must resolve the problem.
(C) The architect must have resolved the problem.
(D) The architect should resolve the problem.
**✅ Answer: (B)**
**📖 Explanation:** The passive modal "must be resolved" reverts to active "must resolve".
**❌ Why (A) is wrong:** Missing the modal.
**❌ Why (C) is wrong:** Perfect modal (must have + V3).
**❌ Why (D) is wrong:** Changed 'must' to 'should'.
**📏 Rule:** Modal + be + V3 -> Modal + V1.
**⚡ Shortcut:** Keep the same modal!
**📊 Difficulty:** Easy
**🏢 Company:** Capgemini

**Q5. Change to Passive: "The manager laughed at the absurd suggestion."**
(A) The absurd suggestion was laughed by the manager.
(B) The absurd suggestion was laughed at by the manager.
(C) The absurd suggestion was being laughed at by the manager.
(D) The absurd suggestion is laughed at by the manager.
**✅ Answer: (B)**
**📖 Explanation:** "Laughed at" is a phrasal verb. The preposition 'at' must remain attached to the verb in the passive voice.
**❌ Why (A) is wrong:** Missing 'at'.
**❌ Why (C) is wrong:** Tense changed to continuous.
**❌ Why (D) is wrong:** Tense changed to present.
**📏 Rule:** Do not drop prepositions of phrasal verbs.
**⚡ Shortcut:** Verb + Preposition + by.
**📊 Difficulty:** Hard
**🏢 Company:** Accenture

**Q6. Change to Passive: "I know him well."**
(A) He is known by me well.
(B) He is known to me well.
(C) He was known to me well.
(D) He has known to me well.
**✅ Answer: (B)**
**📖 Explanation:** The verb "know" in passive voice takes the preposition "to", not "by". The tense is Simple Present, so "is known".
**❌ Why (A) is wrong:** Uses "by".
**❌ Why (C) is wrong:** Simple Past tense.
**📏 Rule:** Known to, surprised at, filled with.
**⚡ Shortcut:** Know = To.
**📊 Difficulty:** Medium
**🏢 Company:** Cognizant

**Q7. Change to Passive: "Close the terminal."**
(A) You should close the terminal.
(B) The terminal must be closed.
(C) Let the terminal be closed.
(D) The terminal is requested to be closed.
**✅ Answer: (C)**
**📖 Explanation:** For direct commands, the standard passive structure starts with "Let".
**❌ Why A & B are wrong:** Modals change the tone from a direct command to advice/obligation.
**❌ Why (D) is wrong:** It is not a request (no "please").
**📏 Rule:** V1 + Object -> Let + Object + be + V3.
**⚡ Shortcut:** Command -> Let.
**📊 Difficulty:** Easy
**🏢 Company:** TCS

**Q8. Change to Active: "The building was heavily damaged by the fire."**
(A) The fire has heavily damaged the building.
(B) The fire heavily damaged the building.
(C) The fire had heavily damaged the building.
(D) The fire was heavily damaging the building.
**✅ Answer: (B)**
**📖 Explanation:** "was damaged" is Simple Past passive. It converts to Simple Past active "damaged".
**❌ Why (A) is wrong:** Present Perfect.
**❌ Why (C) is wrong:** Past Perfect.
**❌ Why (D) is wrong:** Past Continuous.
**📏 Rule:** was/were + V3 -> V2.
**⚡ Shortcut:** "Was + V3" without "being" means it came from Simple Past (V2).
**📊 Difficulty:** Medium
**🏢 Company:** IBM

**Q9. Select the sentence that CANNOT be changed into Passive Voice.**
(A) The CEO announced the merger.
(B) The system runs on Linux.
(C) She gave him the password.
(D) The developer deleted the database.
**✅ Answer: (B)**
**📖 Explanation:** "Runs" here is used intransitively. "On Linux" is a prepositional phrase, not a direct object. Therefore, there is no object to become the subject of a passive sentence.
**❌ Why A, C, D are wrong:** All have direct objects (merger, password, database) and are transitive.
**📏 Rule:** Intransitive verbs cannot be passivized.
**⚡ Shortcut:** If you ask "What?" or "Whom?" after the verb and get no answer, it can't be passive.
**📊 Difficulty:** Hard
**🏢 Company:** Wipro

**Q10. Change to Passive: "People say that the company will go bankrupt."**
(A) The company is said to go bankrupt by people.
(B) It is said that the company will go bankrupt.
(C) The company will be said to go bankrupt.
(D) That the company will go bankrupt is said by people.
**✅ Answer: (B)**
**📖 Explanation:** This is an impersonal passive. "People say that X" becomes "It is said that X" or "X is said to...". Option B perfectly matches the "It is said" structure.
**❌ Why (A) is wrong:** Awkward and incorrectly structured. "The company is said to be going bankrupt" would be better.
**❌ Why (C) & (D) are wrong:** Grammatically distorted.
**📏 Rule:** People/They say that S + V -> It is said that S + V.
**⚡ Shortcut:** "People say" -> "It is said".
**📊 Difficulty:** Hard
**🏢 Company:** Infosys

**Q11. Change to Passive: "Did the intern write this spaghetti code?"**
(A) Was this spaghetti code written by the intern?
(B) Did this spaghetti code be written by the intern?
(C) Had this spaghetti code been written by the intern?
(D) This spaghetti code was written by the intern?
**✅ Answer: (A)**
**📖 Explanation:** "Did" (Simple Past) changes to "Was/Were" in the passive voice. Maintain the interrogative word order.
**❌ Why (B) is wrong:** "Did... be" is ungrammatical.
**❌ Why (C) is wrong:** Past Perfect tense.
**❌ Why (D) is wrong:** Declarative word order, not interrogative.
**📏 Rule:** Did + S + V1 + O -> Was/Were + O + V3 + by + S.
**⚡ Shortcut:** Did -> Was/Were.
**📊 Difficulty:** Medium
**🏢 Company:** Capgemini

**Q12. Change to Passive: "He handed the supervisor a sealed envelope."**
(A) A sealed envelope was handed the supervisor by him.
(B) The supervisor was handed a sealed envelope by him.
(C) A sealed envelope handed to the supervisor by him.
(D) The supervisor had been handed a sealed envelope by him.
**✅ Answer: (B)**
**📖 Explanation:** This sentence has two objects (supervisor, envelope). When making the indirect object (supervisor) the subject, the sentence flows most naturally. (A is missing 'to' before supervisor. C lacks the 'was' auxiliary. D changes the tense).
**📏 Rule:** IO + DO -> IO + be + V3 + DO + by + Subject.
**⚡ Shortcut:** Make the person the subject in the passive voice for double objects.
**📊 Difficulty:** Medium
**🏢 Company:** TCS NQT

**Q13. Change to Active: "My laptop has been stolen!"**
(A) Someone stole my laptop.
(B) Someone has stolen my laptop.
(C) Someone had stolen my laptop.
(D) They steal my laptop.
**✅ Answer: (B)**
**📖 Explanation:** "has been stolen" is Present Perfect passive. Convert to Present Perfect active "has stolen". We supply the indefinite subject "Someone".
**❌ Why (A) is wrong:** Simple Past tense.
**❌ Why (C) is wrong:** Past Perfect.
**📏 Rule:** has/have been + V3 -> has/have + V3.
**⚡ Shortcut:** Keep 'has/have', drop 'been'.
**📊 Difficulty:** Easy
**🏢 Company:** Accenture

**Q14. Change to Passive: "They are not repairing the server."**
(A) The server is not repaired by them.
(B) The server has not been repaired by them.
(C) The server is not being repaired by them.
(D) The server was not being repaired by them.
**✅ Answer: (C)**
**📖 Explanation:** Present Continuous ("are repairing") needs "being". "The server" is singular, so "is not being repaired".
**❌ Why A, B, D are wrong:** Wrong tenses or missing 'being'.
**📊 Difficulty:** Easy
**🏢 Company:** Cognizant

**Q15. "Please review my PR." (Change to Passive)**
(A) Let my PR be reviewed.
(B) My PR should be reviewed.
(C) You are requested to review my PR.
(D) My PR is requested to be reviewed.
**✅ Answer: (C)**
**📖 Explanation:** Imperative sentences starting with "Please" or "Kindly" are converted using "You are requested to".
**❌ Why (A) is wrong:** Used for direct commands, ignores the polite request.
**📏 Rule:** Please + V1 -> You are requested to + V1.
**⚡ Shortcut:** Please = You are requested.
**📊 Difficulty:** Medium
**🏢 Company:** IBM

**Q16. Change to Passive: "Nothing can alter his decision."**
(A) His decision can be altered by nothing.
(B) His decision cannot be altered.
(C) His decision could not be altered.
(D) His decision can be altered by nobody.
**✅ Answer: (B)**
**📖 Explanation:** "Nothing" gives a negative meaning. In passive voice, we make the verb negative ("cannot be altered") and drop the vague subject "by nothing". Option A is technically grammatical but extremely awkward and non-standard.
**❌ Why (C) is wrong:** Changed tense to past ('could').
**📏 Rule:** Nobody/Nothing (Subject) -> Make Verb Negative, drop 'by Nobody/Nothing'.
**⚡ Shortcut:** Nothing + Verb -> Cannot be + V3.
**📊 Difficulty:** Hard
**🏢 Company:** Wipro

**Q17. Change to Passive: "We have to write the script."**
(A) The script have to be written by us.
(B) The script has to be written by us.
(C) The script had to be written by us.
(D) The script is written by us.
**✅ Answer: (B)**
**📖 Explanation:** "Have to" acts as a modal of obligation. Passive structure is "has/have to be + V3". Since "script" is singular, it becomes "has to be written".
**❌ Why (A) is wrong:** Subject-Verb disagreement (script have).
**❌ Why (C) is wrong:** Changed to past obligation.
**📏 Rule:** have to / has to / had to + V1 -> have to / has to / had to + be + V3.
**⚡ Shortcut:** Don't forget to match has/have with the NEW singular/plural subject.
**📊 Difficulty:** Medium
**🏢 Company:** TCS

**Q18. "Your behavior surprises me." (Change to Passive)**
(A) I am surprised at your behavior.
(B) I am surprised by your behavior.
(C) I was surprised at your behavior.
(D) I am surprised with your behavior.
**✅ Answer: (A)**
**📖 Explanation:** "Surprise" takes the fixed preposition "at" in the passive voice. The tense is Present, so "am surprised".
**❌ Why (B) is wrong:** Uses "by".
**❌ Why (C) is wrong:** Past tense.
**❌ Why (D) is wrong:** "With" is used for "satisfied/disgusted".
**📏 Rule:** Surprised + at.
**⚡ Shortcut:** Surprised -> at.
**📊 Difficulty:** Hard
**🏢 Company:** Infosys

**Q19. Change to Passive: "What did he say?"**
(A) What was said by him?
(B) What did say by him?
(C) What had been said by him?
(D) What he said was?
**✅ Answer: (A)**
**📖 Explanation:** "What" acts as the object in the active voice. It becomes the subject in the passive voice. "Did say" (Past) becomes "was said".
**📏 Rule:** What + did + S + V1 -> What + was + V3 + by + S.
**⚡ Shortcut:** Did -> Was.
**📊 Difficulty:** Medium
**🏢 Company:** Capgemini

**Q20. Identify the Voice: "The new feature is being rolled out tomorrow."**
(A) Active Voice
(B) Passive Voice
(C) Impersonal Voice
(D) None of the above
**✅ Answer: (B)**
**📖 Explanation:** "is being rolled out" follows the "be + being + V3" structure, which is the hallmark of Present Continuous Passive. The doer (e.g., by the dev team) is omitted.
**📊 Difficulty:** Easy
**🏢 Company:** Accenture

**Q21. Change to Passive: "One should keep one's promises."**
(A) Promises should be kept by one.
(B) One's promises should be kept.
(C) Promises should be kept.
(D) Promises should have been kept.
**✅ Answer: (C)**
**📖 Explanation:** When the subject is a vague pronoun like "One" or "People", it is generally dropped in the passive voice. "One's" is also dropped to generalize the statement.
**❌ Why (A) & (B) are wrong:** Clunky and redundant to include "one".
**📏 Rule:** Vague subjects (one, someone, they, people) are usually omitted in passive.
**⚡ Shortcut:** Drop "One" completely.
**📊 Difficulty:** Hard
**🏢 Company:** Cognizant

**Q22. Change to Passive: "It is time to deploy the app."**
(A) It is time that the app should be deployed.
(B) It is time for the app to be deployed.
(C) The app is to be deployed on time.
(D) It was time for the app to be deployed.
**✅ Answer: (B)**
**📖 Explanation:** Fixed structure transformation. "It is time to + V1 + Object" becomes "It is time for + Object + to be + V3".
**❌ Why A, C, D are wrong:** Do not follow the structural rule or change tense.
**📏 Rule:** It is time to + V1 + O -> It is time for + O + to be + V3.
**⚡ Shortcut:** Add "for [Object]".
**📊 Difficulty:** Expert
**🏢 Company:** TCS NQT

**Q23. Change to Passive: "Women like men to flatter them."**
(A) Men are liked by women to flatter them.
(B) Women like to be flattered by men.
(C) Women like that men should flatter them.
(D) Men like to flatter women.
**✅ Answer: (B)**
**📖 Explanation:** The infinitive phrase "to flatter them" is converted to passive "to be flattered". The main subject and verb "Women like" remain unchanged.
**📏 Rule:** Subject + Verb + Object + Infinitive -> Subject + Verb + to be + V3 + by + Object.
**⚡ Shortcut:** Change the infinitive to passive (to be + V3).
**📊 Difficulty:** Hard
**🏢 Company:** IBM

**Q24. Change to Active: "By whom was this repository created?"**
(A) Who was created this repository?
(B) Who creates this repository?
(C) Who created this repository?
(D) Whom created this repository?
**✅ Answer: (C)**
**📖 Explanation:** "By whom" reverts to "Who". "was created" (Simple Past) reverts to "created".
**❌ Why B is wrong:** Present tense.
**❌ Why D is wrong:** "Whom" is objective; we need the subjective "Who" to perform the action.
**📊 Difficulty:** Medium
**🏢 Company:** Wipro

**Q25. Change to Passive: "They have built a new server farm."**
(A) A new server farm was built by them.
(B) A new server farm had been built by them.
(C) A new server farm has been built by them.
(D) A new server farm is built by them.
**✅ Answer: (C)**
**📖 Explanation:** "have built" is Present Perfect. Passive is "has/have been built". Since "server farm" is singular, we use "has been built".
**❌ Why (A) is wrong:** Simple past.
**❌ Why (B) is wrong:** Past perfect.
**📏 Rule:** Present perfect requires "has/have been + V3".
**⚡ Shortcut:** Keep it present perfect! Match singular/plural subject.
